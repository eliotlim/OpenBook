# HTML export — island-hydrated vendored viewer

Every standalone HTML export is three layers in one file:

1. **Static first-paint body** — the `renderBlocks` projection. Readable
   without JS, fully computed at export time (expression values, kit-chart
   SVGs, resolved images), and the surface the PDF pipeline snapshots.
2. **Source island** — the inert `application/openbook+json` `<script>`
   carrying the lossless snapshot (block-doc + `assetId`s intact). The single
   source of truth: re-import reads it, and the viewer mounts from it.
   Consumers holding the file as a *string* must extract it with the sdk's
   `readIslandRaw`/`readIsland` (string/regex — never a DOM parser).
3. **Vendored viewer** — `vendor/openbook-viewer.js` (the real OpenBook block
   renderer, self-contained IIFE built by `vite.viewer.config.js`) plus a boot
   script that parses the island and mounts `OpenBookViewer` over the static
   body: locked-but-interactive, zero network, works from `file://`.

Runtime selection (`document_` in `toHtml.ts`):

| Export | Content | Runtime |
| --- | --- | --- |
| `toHtml` (page) | block-doc | viewer (hydrated) |
| `toHtml` (page) | legacy EditorJS snapshot | bespoke `#ob-data` runtime |
| `toHtmlSite` | all pages block-doc, **no databases** | viewer + `#page=` hash nav |
| `toHtmlSite` | any database / any legacy page | legacy `NAV` router + runtime |
| `toSlideDeck` | any | legacy deck (`SLIDE_NAV` + runtime) — viewer deck mode is a follow-up |

PDF: `toPdf`/`toPdfSlides` inject `window.__OB_NO_HYDRATE` into the iframe, so
the viewer boot no-ops and the PDF snapshots the static projection (identical
pixels to the pre-viewer output; the legacy runtime still runs where emitted).

## Block coverage (exported behavior → test)

Tests: `ui-unit` = `packages/ui/src/export/__tests__`,
`parity` = `packages/web/e2e-viewer/export-parity.spec.ts` (hydrated file://
export, generated by `exportParityFixtures.test.ts` — `pnpm test:e2e:viewer`),
`bundle` = `packages/web/e2e-viewer/viewer-bundle.spec.ts`,
`app-e2e` = `packages/web/e2e/export.spec.ts` (real in-app export download).

| Block | Exported behavior (hydrated) | Test |
| --- | --- | --- |
| paragraph / rich text (bold, colour, links) | static + viewer text, read-only, no `contenteditable` | parity; ui-unit `exportViewer`, `exportReactive` |
| heading | real heading levels, static + hydrated | parity |
| slider | live: drags recompute the whole scope | parity (keyboard drag); app-e2e |
| live code (`code` + `live`) | evaluated in doc order; output row updates | app-e2e (`.obe-code-out`); parity via chart chain |
| formula | recomputes over inputs | parity (`.obe-formula-out` 240→242) |
| kitchart (line/bar/…) | SVG baked statically; redraws live on input change | parity (innerHTML changes); app-e2e (bar rects) |
| statuslight | 3-state from expression; flips live | parity (ok→bad); app-e2e |
| progressbar | percent readout baked; live under viewer | parity fixture (static `width:72%` asserted in ui-unit `exportReactive`) |
| radio / dropdown / toggle / action button | fully operable, drive recompute | app-e2e |
| tabs | switch freely, contents locked | parity |
| accordion | sections collapse/re-expand (reader navigation) | parity; ui-unit `readOnly.test` (app path) |
| group | renders + namespaces scope; author chrome hidden | parity (`.obe-group-btn` hidden); bundle |
| table | static `<table>` + viewer TableView, cells locked | parity (cells + no `contenteditable`) |
| todo / checklist | rendered, checkbox disabled | parity fixture |
| image (data-URI / assetId→data-URI) | decodes offline, in both layers | parity (naturalWidth); ui-unit `exportImages` |
| hostile text (`</script>`, `<!--`) | inert text; island unbroken | parity; ui-unit `exportIsland`, `exportViewer` |
| mentions / subpages (site) | navigate between bundle pages | bundle (mention click); parity site nav |
| databases (site) | legacy router + static tables (viewer roster mode pending) | ui-unit `exportViewer` fallback; `e2e/export-html.spec.ts` |
| slide decks | legacy deck nav + runtime (viewer deck mode pending) | ui-unit `exportViewer`, `exportReactive`; `e2e/pdf-export` slides |

Degradation with JS disabled: the static body (all text, baked charts/values,
images, database tables) stays readable; widgets are inert, site exports show
only the root page, tabs show the first tab, accordions are native
`<details>` (still openable without JS). Covered by the parity suite's
`javaScriptEnabled: false` test.
