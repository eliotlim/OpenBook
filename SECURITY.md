# Security Policy

## Supported versions

Only the latest OpenBook release is supported. Desktop builds use the built-in
updater, so please install any available update before reporting or reproducing
a problem.

## Reporting a vulnerability

Email **security@lab255.io** privately. **Do not open a public issue for a
security bug.** Include reproduction steps and the affected OpenBook version
and platform.

Lab255 Private Limited aims to acknowledge reports within 5 business days and
will work with you to coordinate disclosure. For general, non-security help,
email **help@lab255.io**.

## Scope

The OpenBook desktop app, the account and forwarding services at **book.pub**
and **book.cloud**, and the OpenBook plugin registry are in scope. Third-party
plugins are the publisher's responsibility; report issues to their publisher.
